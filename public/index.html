For AI System Prompts

Add this to your system instructions:

When writing markdown, embed relevant images/gifs using direct-img.link — a free image search proxy that returns images directly from a URL. But keep it entertaining, for example use it to show reaction faces, girl, or fun, not technical.
Example structure:
![Cat Gif](https://direct-img.link/cat+gif)
Use images to complement your responses, powered by Brave.

Usage

Embed directly in your markdown files:

![orange cat](https://direct-img.link/orange+cat)

Not the image you wanted? Add ?i=2 (up to 40) to serve the next one:

![orange cat](https://direct-img.link/orange+cat?i=2)

* Note: Literal dots (.) and slashes (/) are rejected to prevent bot abuse. Use %2E or %2F if your query requires them.

Free Images

Need images you can publish? free.direct-img.link only serves images marked free of restrictions (public domain or CC0), so no credit is needed.

![orange cat](https://free.direct-img.link/orange+cat)
![orange cat](https://free.direct-img.link/orange+cat?i=2)
![orange cat](https://free.direct-img.link/orange+cat?src=wikimedia&i=2)
ParamValuesDefault
srcopenverse, wikimediaOpenverse, then Wikimedia
i1–20 (which result)1

* Both params are optional and work in any order. Only free images are served, so if there are none you get bad.webp instead of an AI image. With src, only that source is searched. Licenses come from each source and can be wrong, so check the original before publishing. Images from Openverse (made using the Openverse API, not endorsed or certified by Openverse) and Wikimedia Commons.

AI Images

ai.direct-img.link generates an image of anything instead of searching, so it never comes up empty. Expect soft, painterly, abstract results: the right colors and mood, not always the exact thing.

![frog wizard](https://ai.direct-img.link/frog+wizard)
![frog wizard](https://ai.direct-img.link/frog+wizard?i=2)
![frog wizard](https://ai.direct-img.link/frog+wizard?src=auroraimg-6m&i=2)
ParamValuesDefault
srcauroraimg-6mauroraimg-6m
i1–1000 (a different image each)1

* The same query always gives the same image. When a search on direct-img.link has fewer than ?i= working images, an AI image is served instead. Made with AuroraIMG-6M.

Rate Limits

ScopeLimitAction
Burst~20 req/10s per IPHTTP 429 (~10s)
New Searches35 per day per IPLimit image served
New Free Searches100 per day per IPLimit image served
New AI Images100 per day per IPLimit image served

* free.direct-img.link and ai.direct-img.link each have their own daily limit, separate from the main site's. Cached images don't count toward it and keep loading after you hit it. Neither do other ?i= values of a query searched in the last hour. The burst limit applies to all image requests and is enforced approximately. The daily limit resets at 00:00 UTC.

Caching

Images are cached for 90 days. Subsequent requests for the same query are served instantly. A search's results are kept for an hour, so trying other ?i= values right after is free and fast. An ?i= past a search's working images on direct-img.link serves an AI image instead, cached the same way.
